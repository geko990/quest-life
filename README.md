Il tuo eroe cresce con la tua vita: abitudini, missioni, salute e finanze in un'unica avventura.

**Apri l'app:** https://geko990.github.io/quest-life/
Su iPhone: aprila in Safari → Condividi → "Aggiungi alla schermata Home".

I tuoi dati restano solo sul tuo telefono.

Hai trovato un errore? Nell'app: Opzioni → Registro errori → "Segnala su GitHub",
oppure apri una issue in questo repository.
